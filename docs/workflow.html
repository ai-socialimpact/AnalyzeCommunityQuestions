Phase 1

Ingest (Raw Community Feed)

Ingests 18,044 conversational inquiries from the logging stream. Data contains phonetic variations, greetings, and spelling mutations that defeat traditional rule-based filters.

⚠️ No cleaning is applied here; captures raw user demand baseline.
Phase 2

Embed (Semantic Translation)

Pipes text into gemini-embedding-2 for a 3,072-D dense coordinate matrix. Maps intent, bypasses errors, and caching coordinates saves cloud costs.

💡 One-time conversion saves downstream lookups.
Phase 3

Cluster (Intention Isolation)

Runs a 12-iteration hyperparameter grid search. Optimizes for the Relative Validity Index (RVI) via GPU-accelerated cuUMAP and HDBSCAN.

💡 Isolates 419 micro-intents with zero group overlap.
Phase 4

Translate (Canonical LLM Map)

Uses cosine geometry to pull a balanced context slice (top 10 repeaters + 20 outliers). Gemini Pro maps vector crowds to human-intelligible questions.

💡 Compresses machine data to ease reviewer fatigue.
Phase 5

Output (The Taxonomic Consistency Lock)

Because LLMs are stateless across sequential generation loops, unguided pipelines invent conflicting taxonomies. Phase 5 fixes this by streaming a pre-approved taxonomy file into a strict Pydantic response schema window. Resulting sheet has broad summaries, canonical questions, and indexing meta-tags.
